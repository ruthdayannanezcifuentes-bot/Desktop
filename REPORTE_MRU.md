# Informe de Laboratorio: Movimiento Rectilíneo Uniforme

## 1. Cálculo de Velocidad
La velocidad constante se determinó mediante la relación:
$v = \frac{x_2 - x_1}{t_2 - t_1}$

Para los datos registrados:
- $v = \frac{11 - 5}{2 - 0} = 3$ m/s.

## 2. Ecuación de Movimiento
La posición en función del tiempo está definida por:
- **$x(t) = 5 + 3t$**

## 3. Condiciones Iniciales
En el instante t = 0 s, la posición registrada es:
- **$x_0 = 5$ metros**.

## 4. Gestión de Versiones y Resolución de Conflictos
Ante la presencia de modificaciones concurrentes en distintas ramas sobre el mismo archivo, Git señalará un conflicto de fusión. El procedimiento de resolución implica la edición manual para consolidar los cambios y la eliminación de las etiquetas de control antes de realizar el commit de integración.
